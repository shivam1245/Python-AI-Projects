Tier 1 Features

High-impact additions shipped in v2.0 — face detection, emotion AI, unlimited classes, and confidence scoring.

👤

Face Detection with Bounding Box

Implemented

Toggle a real-time green bounding box drawn around every detected face using OpenCV's built-in Haar cascade. No extra packages needed.

  • Detects multiple faces simultaneously
  • Visual "Face" label above each box
  • Toggle ON/OFF without restarting
No extra dependenciescv2.CascadeClassifier

Emotion Analysis

Implemented

Powered by FER + TensorFlow. Analyzes faces every 10 frames (~150 ms) and overlays an orange bounding box with the dominant emotion and confidence.

Multi-Class Classification

Implemented

Extends the classifier from 2 fixed classes to any number. Click "+ Add Class" to add more at runtime.

  • Dynamic class buttons added at runtime
  • SVM natively handles N-class problems
  • Separate numbered folders per class
No extra dependencies
📊

Confidence Score

Implemented

The SVM is trained with probability=True. Confidence % is shown alongside the predicted class label.

  • Shown as % on every prediction
  • Helps spot uncertain predictions
  • Works with 2 or more classes
No extra dependencies

🚀 Get Started

Installation & Usage

Up and running in under two minutes.

01

Clone & create a virtual environment

git clone <repo-url>
cd Python-AI-Projects
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # macOS/Linux
02

Install dependencies

pip install -r CameraClassifier/requirements.txt
pip install flask  # for the web server
pip install fer tensorflow  # for emotion analysis
03

Start the web server

cd CameraClassifier/website
python server.py
# Open http://localhost:5000
04

Or run the desktop app

# From repo root
python -m CameraClassifier.main
